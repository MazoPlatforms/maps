# Geographic editor

Build an assembled canonical artifact as described in `api-sdk.md`. On the existing MapLibre website choose **Independent Mazo sample**, then **Edit Mazo sample**. The default national viewer remains available. The independent sample uses complete Mazo records, not permanent upstream overrides. It currently covers bounded places/buildings/roads and one authoritative Colombo DS boundary, not every feature in the bounding box.

Select a visible canonical feature. The inspector loads its full record and expected revision hash. Edit the primary English name, Tamil/Sinhala fields and JSON properties. The marker represents the selected vertex; drag it or enter longitude/latitude and choose **Move vertex**. The vertex number selects a coordinate across polygon rings or multipart geometry. Add/remove vertices preserves polygon closure. **Move feature here** translates the geometry from its first vertex. Changes are highlighted and original versions are suppressed to avoid duplicate rendering. **Before / after** switches between original and edited views.

To create a feature, supply your name and an HTTPS source URL, choose type/geometry, select **Draw**, click/tap positions, then **Finish**. Points complete on the first click. New road segments create two canonical endpoint connectors atomically; access starts as unknown and the car graph excludes the road until access is explicitly reviewed. Lines require two distinct positions; polygon rings need three vertices and close automatically. Water can be a point, line or polygon. Complex polygon validity is authoritatively checked in CI; the browser provides early bounds/closure/degeneracy feedback. Administrative proposals do not replace the pinned Survey Department/OCHA classifier and require elevated review.

**Delete** retains an existing feature as a proposed tombstone; deleting an unsubmitted new feature removes that draft. **Undo/redo**, **Save draft**, **Restore draft**, and **Discard all** affect only your device. Draft restoration requires the same dataset version to prevent silent stale edits. Storage failures appear as errors. A multi-feature changeset may contain up to 100 operations. **Preview changeset** shows exact operations; **Download & submit** downloads JSON and presents GitHub fork/upload/PR steps. No geographic save is claimed until review, merge and a successful release publication occur.

Source IDs, origin fingerprints and licensing cannot be overwritten via ordinary canonical operations. Existing provider references survive replacing properties. Browser geometry checks are intentionally less complete than GEOS/JSON Schema/administrative checks in CI. A browser-valid draft can still be rejected for invalid self-intersection, source mismatch, stale versions, boundary coverage, references or supported-network connectivity regressions.

## Incomplete editor capabilities

Road split/merge is implemented for compatible single LineString segments with explicit connectors and without scoped/turn/destination rules. Splitting at an interior vertex creates a second permanent road and a new canonical connector while retaining provenance; merging requires forward geometry order, matching connector identity and compatible metadata/access/classification. Complex scoped split/merge, dedicated access-rule/connector forms, safe level-aware movement and certified routing-network editing remain incomplete. Do not use JSON editing to invent relationships or bypass failed connectivity checks. The generic properties editor is not a substitute for a verified topology editor. Source road connectivity is preserved from explicit connector references; the validator detects inconsistent supported-graph node coordinates and surviving-component disconnections. It does not certify every unsupported restriction/turn condition.

Current desktop/mobile layout and tested operations are listed in `release-acceptance.md`; untested behavior must not be marked complete. Android device and accessibility audits remain open even where a Chromium mobile viewport test passes. Large or highly multipart geometry performance has not been certified for mobile devices.
