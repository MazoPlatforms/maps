# Offline sample and routing

The website lists the one actual available region from the release inventory and offers **Download offline map sample**. Unknown region IDs are rejected; the pilot region remains marked incomplete and no unavailable districts are advertised as complete. Canonical offline styles use locally generated MapLibre glyph ranges and a self-hosted HarfBuzz complex-text plugin for Tamil. Sinhala and English use the local Noto glyph bundle. A language selector switches canonical symbol layers among English, Tamil and Sinhala, with English fallback when a translation is missing. Rendered labels use NFKC while source spellings remain intact in canonical records. The plugin, 30 encoded glyph ranges and Noto fonts are pinned, checksum-validated, offline-packaged and accompanied by MIT, Apache-2.0, BSD-3-Clause and SIL OFL notices. A real disconnected Chromium check used the OCHA Colombo boundary record (`கொழும்பு` / `කොළඹ`), observed both symbol features placed and a local encoded Tamil glyph request. This verifies that sample path; it does not imply nationwide coverage, device-level visual certification or coverage for all names/scripts.

`OfflineManager` registers the same-origin, repository-subpath service worker, checks storage estimates, downloads a versioned inventory, verifies each file's length/SHA-256, and activates the new region only after every file succeeds. Interrupted downloads retain completed verified files; retry resumes and replaces corrupt entries. The previous complete cache remains active if an update fails. Updates reuse checksum-matching cached resources, including across cached release versions; activation still requires complete verification; no binary PMTiles delta is claimed. `hasUpdate()` compares available vs installed release versions. Old caches may be removed with **Remove offline sample**. **Check sample updates** compares the installed and available release. Installer fetches explicitly bypass the old worker cache so changed resources can update safely; normal reads keep the complete verified active cache. Offline navigation selects the independent glyph-enabled canonical view. Offline caches are copies, not the canonical public database.

The worker verifies cached bytes and serves real byte-range responses from a complete cached PMTiles archive. Corrupt cached bytes produce a repair error rather than silently drawing wrong data. Large full-archive range handling allocates the archive in memory; this is bounded to the small regional archive, not national offline capacity. Browser eviction, quotas and private-mode limitations can remove data; user-visible error handling is present, but actual low-memory Android behavior remains unverified.

The experimental car router uses Mazo-owned road geometry and explicit preserved connector relationships. Physical visual crossings are never joined automatically. Graph nodes have permanent Mazo-derived IDs; missing standalone connector records are not fabricated as authoritative point records. Native edited roads can reference canonical connector IDs. Unsupported scoped/temporal/vehicle restrictions, construction, unsupported classes and turn-sequence segments are excluded with reasons. Simple directional/access rules are compiled; class-based speeds estimate travel time and do not represent traffic observations.

The browser snaps origin/destination to routable segment interiors, inserts temporary graph positions, and computes a directed shortest-time graph path. It returns actual road geometry, distance, estimated time, snapped coordinates and road IDs. Reverse one-way travel and unreachable destinations fail. No straight-line route substitutes are used. The current graph is from 2,000 sampled segments, not a complete district or national network; 338 unsupported/restricted source segments were excluded in the measured build. Route results are not navigation guidance or turn-by-turn instructions.

The existing website has coordinate-entry route controls and draws the result. Source updates rebuild the graph from accepted full canonical records. Snapshot validation detects inconsistent shared connector coordinates and supported surviving-component disconnections. Complete level/turn restriction handling and complex scoped split/merge editing remain blockers before routing can be treated as production quality.
