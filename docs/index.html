Project documentation

A map is a beginning.

Mazo Maps is an open-source mapping project by Mazo Platforms, Inc. These notes describe what is live today, how the site is assembled, and how future geographic data can be added with provenance intact.

Current experience

The website renders an interactive MapLibre map centered on Colombo using OpenFreeMap's public vector styles and OpenStreetMap data. The center is a viewing choice only; it does not represent a service boundary or guarantee data coverage. The map needs an internet connection. If the map provider or renderer is unavailable, the surrounding documentation remains accessible.

There are no accounts, tracking features, project-owned POIs or custom geographic datasets in this first version. No API key is embedded in the site.

Architecture

The static site separates presentation, map configuration and data-source registration. This keeps the renderer replaceable and gives future vector-tile or POI integrations an explicit place to document format, license, source IDs and refresh behavior.

index.html                 Landing page
assets/css/site.css        Responsive layout and themes
assets/js/app.js           Theme controls and map initialization
assets/js/config.js        Map settings and source registry
data/overture/             Future data integration notes
docs/                      Project documentation

Data provenance

OpenFreeMap supplies the styles and vector tiles. The visible map attribution identifies OpenFreeMap, OpenMapTiles and OpenStreetMap contributors. OpenStreetMap data is available under the Open Database License (ODbL). OpenFreeMap states that commercial use is allowed and attribution is required; its public service is provided as-is and has no SLA.

Overture Maps and points of interest are planned only. No Overture data or POI layer is currently loaded. Before integration, the project will record the dataset release, license, coverage, transformations and update policy.

Run and contribute

Serve the repository root with a local static HTTP server and open the page in a modern browser. MapLibre GL JS and map tiles load from public providers. Contributions should keep provider configuration free of credentials and retain source attribution.
