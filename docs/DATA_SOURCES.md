# Data sources and provenance

The existing publication pipeline below remains in service during migration. [The canonical v2 pilot](canonical-data.md) imports full source records once and edits/builds them offline. Its provenance fingerprints describe the imported snapshot; upstream is not a continuing validation authority for canonical records.

## Sri Lanka basemap

- **Geographic data:** official Overture Maps release recorded in the active manifest; nationwide refreshes resolve the latest release from Overture STAC.
- **Area:** bbox `[79.3, 5.8, 82.1, 10.1]`, selecting source features whose bounding boxes intersect the requested extent.
- **Themes:** base (land, land cover, land use, water and available supporting layers), transportation (segments and connectors), buildings (buildings and building parts when available), and places (with names where provided by the source).
- **Format and hosting:** four PMTiles archives generated by Overture's published tile pipeline, hosted with the site on GitHub Pages. The actual release, feature row counts, named-row counts, layer list, image digest, archive sizes and hashes are recorded in `data/sri-lanka/manifest.json` after an Actions build.
- **Attribution:** © OpenStreetMap contributors, Overture Maps Foundation. See [Attribution](../ATTRIBUTION.md) and the [Overture attribution guidance](https://docs.overturemaps.org/attribution/).

Counts in the manifest are bbox-filtered source Parquet rows before tile deduplication. They are not the number of features visible at every zoom. Missing source data is not fabricated, and this regional extraction does not imply complete POI coverage or Google Maps equivalence.

## Rendering dependencies

The map renderer is MapLibre GL JS. The PMTiles browser adapter uses HTTP range requests against the same-origin archives. MapLibre label glyphs are retrieved from the public OpenFreeMap font endpoint, which is a third-party service dependency; geographic vector data remains served from this project site.

## Refresh

Nationwide refreshes and national-pipeline changes resolve the latest official Overture release and rebuild the regional archives. Other changes reuse the existing published archives with full checksum verification. The generated manifest identifies the actual release, and browser verification records rendered coverage. If Pages limits block publication, the generated site remains available as a short-lived Actions artifact.

## Administrative classification and contributions

The pinned Survey Department of Sri Lanka / OCHA COD-AB v03 dataset supplies province, district and DS geometry and authoritative parent codes. Its source resource was published on 26 January 2026 with geometry valid on 16 August 2022. The manifest derives the DS count from the imported file. Original geometries and multilingual names remain intact under CC BY 3.0 IGO; complete attribution is in [ATTRIBUTION.md](../ATTRIBUTION.md).

Only added, modified or removed features receive individual contribution records. Unchanged Overture features stay in optimized archives. Sources, IDs, releases, licenses and expected upstream fingerprints remain attached to the sparse records. A changed or missing touched upstream source blocks publication until an explicit reviewed resolution. No synthetic test geometry is included in published geography.
