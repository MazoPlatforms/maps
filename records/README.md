# Reviewed community records

One JSON file per community-maintained feature:
`records/<featureType>/<first-two-UUID-characters>/<UUID>.json`.
There are deliberately no invented production examples. Use the map's Contribute
panel to create a proposal or edit a published community record. See
[CONTRIBUTING.md](../CONTRIBUTING.md) for review, licensing and CLI instructions.

These records supplement the nationwide Overture basemap. They do not duplicate
its millions of buildings. Editing an existing *community* record preserves its
UUID and uses a parent-content hash. Direct replacement/deletion of upstream
Overture features is not enabled: the active basemap has no verified permanent
source IDs. Do not add a second copy of an existing upstream feature as a correction.
