The project

A clearer way
to build on place.

Mazo Maps is an open-source mapping project by Mazo Platforms, Inc. It brings together an interactive map today and a modular path toward richer, responsibly sourced geographic data.

01

Open by default

Build in public with transparent code, data sources and attribution.

02

Designed to compose

Keep the map renderer, styles and data layers distinct so each can evolve.

03

Grounded in sources

Show where map data comes from. Do not imply coverage that has not been verified.
