# Encoded HarfBuzz glyph ranges

These MapLibre glyph PBFs are vendored from `wipfli/pgf-glyph-ranges` at commit `96cbacf2e76adaf0f111d8d082379ee018d0010a`. They encode glyphs used by `wipfli/maplibre-gl-complex-text` and are required by its Tamil HarfBuzz shaping hook. The repository license is in `LICENSE-BSD-3-Clause.txt`; the embedded Noto font has its separate `OFL.txt` notice.

The files are self-hosted and included in the canonical offline inventory. No runtime request to either upstream project is made.
