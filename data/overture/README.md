# Overture data

The current Sri Lanka extract is generated by GitHub Actions and published under `data/sri-lanka/`. This folder is reserved for future Overture source documentation; it contains no duplicate or sample geographic data.

The pipeline reads the latest official release catalog, uses the official Overture bbox filter and tile profiles, and writes a provenance manifest next to the generated archives. See [the data-source notes](../../docs/DATA_SOURCES.md) and [architecture](../../docs/ARCHITECTURE.md).
